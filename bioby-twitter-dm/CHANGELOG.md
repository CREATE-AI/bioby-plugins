# Bioby Twitter DM 更新说明

版本号与 `manifest.json` 的 `version` 一致。每次改插件请：**升版本号 + 在本文件顶部追加条目 + 同步 README 标题**。

## 0.3.13 — 2026-08-20

- 侧栏在当前状态列表内按昵称 / @账号 / 主页链接过滤达人；切换状态清空搜索，刷新保留关键字。

## 0.3.12 — 2026-08-20

- 修复侧栏打开主页/发私信时，X 页 content script 抢收广播消息导致 “message channel closed”。

## 0.3.11 — 2026-08-20

- 查看话术或保存编辑后可点「收起」隐藏正文。

## 0.3.10 — 2026-08-20

- 话术区改为先选模板：点「查看」才展开正文，点「编辑」才出现保存；默认不再直接铺开文本。

## 0.3.9 — 2026-08-20

- 话术可编辑并保存到 `dm_template`（Intro / Follow-up）；未保存禁止发送。
- 切换小号 / 系统数据库时保留个人 ID。
- 设置页不再展示版本功能列表。
- 符合-待建联按 `MATCH + PENDING_PLUGIN` 拉取。

## 0.3.8 — 2026-08-19

状态与报价对齐绑定项：

- 小号筛选项「待建联」改为「符合-待建联」（仍拉 `PENDING_PLUGIN`）。
- 系统数据库已回复线索：原「符合」改为「已报价」，回写 `processStatus=QUOTED`（须已收录报价）；「不符合」不变。
- 收录抽价会把金额写到线索 `minPrice`/`maxPrice`，不自动改成已报价。

## 0.3.7 — 2026-08-19

登录与文案：

- 记住 CRM 密码和个人 ID；重新打开侧栏/popup 会回填，不必每次重填。
- 已有有效 Token 时不强制重新登录；Token 失效时用已保存密码静默重登，失败再提示填密码。
- 文案：「商务号」改为「个人ID」，「大号」改为「系统数据库」。内部取值仍为 `pluginRole=big`、移交目标 `admin`。

## 0.3.6

此前已发布版本（发送校验、批量私信、同步对话抽报价）。详细条目从本版起记录。
