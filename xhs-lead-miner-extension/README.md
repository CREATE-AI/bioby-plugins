# 小红书线索挖掘助手（Chrome 扩展）

通过**模拟人工浏览**小红书网页版搜索结果，采集「美区推广 / 海外红人」相关笔记线索，并导出 CSV。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 开启右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择目录：`xhs-lead-miner-extension`

## 使用

1. 浏览器先**登录** [小红书网页版](https://www.xiaohongshu.com/)
2. 点击扩展图标，配置关键词（默认已填：美区推广、海外红人…）
3. 点击 **开始采集** — 扩展会：
   - 自动打开搜索页
   - 分段滚动、随机停顿（模拟真人）
   - 解析笔记卡片并打分
   - 按关键词依次采集
4. 完成后 **导出 CSV**，在 Excel 中筛选高分线索跟进

## AI 筛选（v1.3）

1. 弹窗填写 **API Key**（OpenAI 兼容：OpenAI / DeepSeek / 月之暗面等）
2. 可选修改 Base URL、模型、最低置信度（默认 0.65）
3. 点 **测试 AI 连接** → **开始采集**
4. 流程：滚动抓卡片 →（可选）挡教程攻略标题 → **批量送 AI 判定** → 仅 `isLead=true` 入库

Key 只存在浏览器本地 `chrome.storage`，不会上传到你们业务后端。

### 常见 Base URL

| 服务 | Base URL | 示例模型 |
|------|----------|----------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 月之暗面 | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |

## 分层筛选规则（未开 AI 时的兜底）


采集时按三层过滤，**未通过的不入库**：

1. **硬排除**：教程、培训、复盘、趋势盘点、招聘、代理招商等
2. **组合必达**（满足其一）：
   - 地区词 + 资源词 + 需求词
   - 需求词 + 资源词 + 搜索词含地区语境
   - 搜索词命中 + 资源词 + 地区/需求信号
3. **分数阈值**：默认 ≥ 65 分才入库（可在弹窗调整）

| 分数 | 等级 |
|------|------|
| ≥ 75 | high（高意向） |
| 60–74 | medium |
| < 最低分 | 丢弃 |

## 采集字段

| 字段 | 说明 |
|------|------|
| noteId | 笔记 ID |
| title / desc | 标题摘要 |
| authorName / authorId | 作者 |
| likes | 点赞（尽力解析） |
| noteUrl | 笔记链接 |
| matchedKeyword | 命中关键词 |
| leadScore | 线索分 0–100 |
| crawledAt | 采集时间 |

## 注意事项

- **频率**：默认已调慢（滚动 2.5–5 秒、词间 8–15 秒、每词最多 5 轮）；仍建议单次少量关键词、低频使用
- **登录**：未登录时搜索结果可能不完整
- **DOM 变化**：小红书页面结构会变，若采不到数据需更新 `content/extractor.js` 选择器
- **私信**：本扩展只负责**发现线索**，不自动发私信；跟进请在企业号/人工渠道完成
- **合规**：仅用于内部运营调研，请遵守平台服务条款

### 默认节奏（v1.1.1）

| 参数 | 值 |
|------|-----|
| 滚动间隔 | 2.5–5 秒 |
| 每 2 轮长停 | 8–15 秒 |
| 换关键词 | 8–15 秒 |
| 打开搜索页后等待 | 3.5–6 秒 |
| 单关键词轮次 | 最多 5 轮 |

## 目录结构

```
xhs-lead-miner-extension/
  manifest.json
  popup/           # 配置与导出 UI
  background/      # 任务编排、开标签页
  content/         # 页面内滚动 + DOM 解析
  lib/             # 存储、打分、导出
```

## 调试

- 在搜索结果页按 F12，Console 查看是否有报错
- `chrome://extensions/` → 扩展详情 → **Service Worker** 查看后台日志
